## To publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload all files to the root of the repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

## Customize before final submission
- Add your own soccer image or screenshot in `notice.html`.
- You can replace any wording with your own style.
- If you want, you can later add more pages or embed Desmos.
